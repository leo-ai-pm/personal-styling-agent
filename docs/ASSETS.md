# 商品与素材

本仓库仅包含自行编制的合成商品、库存、规则和代码生成的 SVG 素材，均按仓库 MIT License 分发。SVG 是商品组合的示意卡片，并非商品外观的精确还原或模特上身图。

原演示使用过人物参考图片及衍生搭配图，其记录仅覆盖原项目的公开演示。因此本开源包不包含参考照片、人物图、生成服务的原始输出、授权对话或人工验收记录。开源示意素材没有继承那些照片的视觉验收结论。

## 可复现来源

- 商品与库存：`data/m1_v2`、`data/m3_draft` 下的 JSON。
- 示意图生成代码：`scripts/generate_sample_assets.py`，不访问网络或模型。
- 图片与 SKU 绑定：各包的 `look_assets.json`，包括 SHA-256。
- 示意素材清单：`provenance/asset_manifest.json`；扩展包另有 `image_jobs.json`。
- `human_visual_acceptance: false` 表示未宣称人工照片验收，文件完整性与视觉质量是不同检查。

重新运行生成脚本会覆盖这些 SVG 及其映射清单，请先保存你自行添加的素材。

## 接入自己的素材

1. 为每件商品创建真实可追溯的产品与 SKU 记录，填写尺码、价格、可售状态和库存。
2. 为每组搭配的 `top`、`bottom`、`shoes` 绑定准确 SKU。当前版本每组需要这三个槽位；单件加购不依赖三件组合图。
3. 使用你有权分发的图片，保存到受控素材目录，并登记准确 SHA-256、来源和适用许可。
4. 如替换为照片，更新资源加载器中的素材类型/授权校验以及 `view`、`disclaimer_code`，保留路径、SKU、摘要校验；不要把照片伪记为 `svg_code`。
5. 检查每张照片与对应商品、姿势、尺码展示边界，再运行数据与业务测试。图像可读不等于视觉内容准确。

有限组合图会限制可推荐组合。即使商品有库存，没有完整组合映射时也不能承诺展示该完整方案。当前实现不在对话时生成新图片。
