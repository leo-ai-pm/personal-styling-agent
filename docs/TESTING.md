## 用例版本

`evals/p0_eval_cases.jsonl` 是原始冻结样例。后续发现其中 5 条期望与临时保留作用范围或执行顺序冲突，因此另外保留 `p0_eval_cases_v2.jsonl`。原始文件与其摘要仍保留，不通过修改原数据掩盖失败。

`m2/tests/semantic_cases.json`、`live_journey_cases.json` 与 `evals/item-cart-followup` 包含语义和多轮案例。单元测试、结构化断言、真实模型输出、人工视觉审核分别记录，不相互代替。

## 开源素材的适配

开源样例使用 `schematic_reference_not_fit`，展示“商品组合示意，不代表实际试穿或尺码效果”。原冻结评测 fixture 仍使用原图像类型与对应提示；服务按实际素材类型选择提示，不把示意卡片描述为 AI 人物照片。

开源特有回归覆盖：不隐式读取用户目录中的模型凭据、SVG 内容类型、私有文件路由不可访问、预算内组合显示且不宣称实际试穿。

## 真实模型评测

配置好服务端 Key 后，参照 README 显式执行 `--mode live`。执行前检查输出路径、用例范围和服务商预算。结果应记录技术错误、业务断言、语义偏差及待复核项；报告含对话内容，默认保存在 Git 忽略的 `reports/`。

尚未针对公网承载、长期可用性或真实转化效果验收。持续集成只跑离线检查，无需配置任何 API key。
